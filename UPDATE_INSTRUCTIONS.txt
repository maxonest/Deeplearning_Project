Deeplearning_Project 最新更新指令
更新时间：2026-06-22

本次更新：新增 LoRA adapter 启用开关。

1. 同步代码

git pull origin main
conda activate DL_lyx

2. 修改 .env

在 LOCAL_MODEL_PATH 和 LOCAL_LORA_ADAPTER_PATH 附近加入：

USE_LORA_ADAPTER=true

完整示例：

USE_LOCAL_MODEL=true
LOCAL_MODEL_PATH=models/qwen/Qwen3.5-9B
USE_LORA_ADAPTER=true
LOCAL_LORA_ADAPTER_PATH=models/qwen/lora_adapter

设置说明：

USE_LORA_ADAPTER=true
加载基础模型后挂载 LoRA adapter。

USE_LORA_ADAPTER=false
只加载基础模型，不挂载 LoRA。LoRA 文件和路径会保留，不需要删除。

3. 重启服务

如果服务正在运行，先按 Ctrl+C 停止，然后执行：

python start_windows.py

本次更新不需要重新安装依赖，也不需要重新构建知识库。

4. 验证

打开：

http://localhost:8000/health

确认返回内容包含：

"use_lora_adapter": true

启用 LoRA 时，后端日志的模型加载阶段会显示实际 adapter 路径；关闭 LoRA 时显示：

lora_adapter=disabled

也可以访问：

http://localhost:8000/api/config

确认 `use_lora_adapter` 与 `.env` 中的设置一致。
