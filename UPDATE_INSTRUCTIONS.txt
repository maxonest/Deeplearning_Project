Deeplearning_Project 最新更新指令
更新时间：2026-06-22

本次更新：新增 RAG 启用开关。

1. 同步代码

git pull origin main
conda activate DL_lyx

2. 修改 .env

加入：

USE_RAG=true

设置说明：

USE_RAG=true
启动时加载并校验本地 FAISS 知识库，专业问题使用 RAG 检索后回答。

USE_RAG=false
不加载、不校验、不查询知识库，所有问题直接由基础模型或 LoRA 回答。

推荐使用以下组合对比回答效果：

基础模型：
USE_LORA_ADAPTER=false
USE_RAG=false

仅 LoRA：
USE_LORA_ADAPTER=true
USE_RAG=false

仅 RAG：
USE_LORA_ADAPTER=false
USE_RAG=true

LoRA + RAG：
USE_LORA_ADAPTER=true
USE_RAG=true

3. 重启服务

如果服务正在运行，先按 Ctrl+C 停止，然后执行：

python start_windows.py

本次更新不需要重新安装依赖，也不需要重新构建知识库。

4. 验证

打开：

http://localhost:8000/health

确认返回内容包含：

"use_rag": true

RAG 关闭时：
- status 应为 ok，而不是 degraded。
- startup_message 显示“模型已就绪，RAG 已关闭”。
- knowledge_base_ready 为 false。
- 前端右侧知识库区域显示“已关闭”。

也可以访问：

http://localhost:8000/api/config

确认 `use_rag` 与 `.env` 中设置一致。
